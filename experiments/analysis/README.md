## `analysis`

In this folder, you will find a collection of scripts that use the preprocessed data to draw conclusions or calculate quantities that will be reported in the manuscript. These include:

- fastsimcoal
    - est and tpl files for six taxon models and two taxon models
    - helper scripts for running fastsimcoal
    - scripts for running bootstrap analyses
- msmc
- phylo: phylogenetic analyses
    - raxml
    - twisst
- calculating generation times
- fd calculations using Dsuite
- recombination rate estimation
