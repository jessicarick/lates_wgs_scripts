## `data`
This directory houses all small (< 100 MB) data sets associated with this project. Data larger than 100 MB can be found on NCBI SRA (i.e., for fastq files for genomic data; GBS: [BioProject PRJNA776855](https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA776855), WGS: [BioProject PRJNA1207083](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1207083/)) or Zenodo (for filtered VCFs; [10.5281/zenodo.23619330](10.5281/zenodo.23619330)).
